# Adoption Kit Example

This is the smallest completed proof folder a repo owner can copy when teaching an agent the Proof Loop shape.

Read:

1. `.agent/tasks/checkout-empty-state-proof/spec.md`
2. `.agent/tasks/checkout-empty-state-proof/evidence.md`
3. `.agent/tasks/checkout-empty-state-proof/verdict.json`
4. `.agent/tasks/checkout-empty-state-proof/problems.md`

Run:

```bash
bin/proof-loop check examples/adoption-kit/.agent/tasks/checkout-empty-state-proof
bin/proof-loop report examples/adoption-kit/.agent/tasks/checkout-empty-state-proof --format md
```
